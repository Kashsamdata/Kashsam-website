# Kashsam Website

This project is a React + Vite website for Kashsam, built with React Router for multi-page navigation and a custom landing-page style.

## Stack

- React
- Vite
- React Router DOM
- Custom CSS styling

## Run locally

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open the local URL shown in the terminal, usually:

- http://localhost:5173/

## Production build

```bash
npm run build
```

## Preview production build

```bash
npm run preview -- --host 0.0.0.0
```
